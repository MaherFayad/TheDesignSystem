Rules to check for each interaction you own, in Studio, Desk, Neutral and Liquid (light;
one dark run per style where color matters), LTR and Arabic RTL, with a pointer, with touch
(phone viewport, hasTouch, page.tap / touchscreen), and with the keyboard:
 1. Only allowed properties animate; no layout property animates or is listed in a transition.
 2. Durations and eases match motion tokens (read --ds-duration-*, --ds-ease-* on the theme
    element and compare); report raw values with file and line.
 3. A reduced form exists and is used under both 'media' and 'attr'. Nothing timed over 0ms
    that moves (travel, scale, turn, clip growth) under either; a fade or color change may stay
    only if the registry's reduced text says so.
 4. No flash over three a second (WCAG 2.3.1); nothing moves past 5s without a pause path (2.2.2).
 5. State, value and focus change at once; motion never delays the action, never moves the
    target from under the pointer (hit test at the rest centre during the motion), never
    blocks input.
 6. A rapid second trigger (30ms) and an interrupted one (reverse before the end) leave no
    stuck state: right final state, transforms and opacity at rest, no held fill, no leftover node.
 7. The state indicator keeps contrast on every frame (sample frames 0 to 500ms every 20ms with
    paused, seeked animations: document.getAnimations().forEach(a => { a.pause(); a.currentTime = t; }),
    then screenshot and measure the indicator against what is behind it).
 8. The focus ring shows at once after Tab (opacity 1 on the first frame) (WCAG 2.4.7).
 9. Staggered text reaches opacity 0.9 within about 200ms.
10. filter and backdrop-filter have a fallback (@supports not, prefers-reduced-transparency,
    prefers-contrast: more, [data-contrast='more']); emulate reduced transparency with
    page.emulateMedia is not available for it, so set it through CDP:
    const cdp = await ctx.newCDPSession(page); await cdp.send('Emulation.setEmulatedMedia',
    { features: [{ name: 'prefers-reduced-transparency', value: 'reduce' }] });
11. forced-colors works: page.emulateMedia({ forcedColors: 'active' }); state still visible.
12. No code waits on transitionend or animationend (grep the component source).
13. A drag interaction has a non drag path (WCAG 2.5.7).
14. A style can turn it off: inject the registry's `off` row under @layer ds.recipes and
    confirm the travel and scale stop.
