# Screenshot matrix, angular

Made by `npm run shots`. Each shot is the `variants` case at `chrome=0`, 1280 by 800 viewport, full page, device scale factor 1, animations off, reduced motion, fonts loaded. File names: `<component>/<style>-<scheme>-<dir>[-<density>][-open].png`. Density is default unless named.

1312 shots, 58 components, 73.76 MB after lossless recompression. Stable (two captures byte equal): 1308; unstable: 4; not verified: 0.

Images kept in this folder: 290 (9.46 MB), copied from the work folder as palette PNGs after the run. A cell with a link is kept here; a cell with a short hash was captured, compared and recorded, and its image is in the work folder `node_modules/.cache/ds-shots/angular` of the run, not in git. Rerun `npm run shots -- --keep all` to get every image.

The full list with sizes and hashes is in `captured.json`.
