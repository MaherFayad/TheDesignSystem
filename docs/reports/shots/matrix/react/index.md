# Screenshot matrix, react

2376 shots, 109 components, 127.15 MB after lossless recompression. Stable (two captures byte equal): 0; unstable: 0; not verified: 2376.

Images kept in this folder: 721 (30.47 MB). A cell with a link is kept here; a cell with a short hash was captured, compared and recorded, and its image is in the work folder `node_modules/.cache/ds-shots/react` of the run, not in git. Rerun `npm run shots -- --keep all` to get every image.

The full list with sizes and hashes is in `captured.json`.
