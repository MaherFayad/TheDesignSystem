# Screenshot matrix, react

Made by `npm run shots`. Each shot is the `variants` case at `chrome=0`, 1280 by 800 viewport, full page, device scale factor 1, animations off, reduced motion, fonts loaded. File names: `<component>/<style>-<scheme>-<dir>[-<density>][-open].png`. Density is default unless named.

2376 shots, 109 components, 125.75 MB after lossless recompression. Stable (two captures byte equal): 2359; unstable: 17; not verified: 0.

Images kept in this folder: 721 (30.18 MB). A cell with a link is kept here; a cell with a short hash was captured, compared and recorded, and its image is in the work folder `node_modules/.cache/ds-shots/react` of the run, not in git. Rerun `npm run shots -- --keep all` to get every image.

The full list with sizes and hashes is in `captured.json`.
