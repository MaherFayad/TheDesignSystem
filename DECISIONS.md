## Consolidation 2 (2026-11-12)

Recorded by the second consolidation pass. Report:
`docs/reports/consolidation-2.md`.

1. **Private property names (anatomy rule 1).** The name list in
   `docs/contracts/anatomy.md` now has kinds: the base list, part names, a
   working `-now` value, tone groups, layout, motion and drawing extras.
   Added suffixes: `-invalid`, `-checked`, `-readonly`. Added base names:
   `padding-block`, `font-weight`, `border-style`, `shadow`. Any other
   name needs a line in the CSS header. Reason: lanes had already used
   these names in the same way (consolidation 1, lanes 2D, 3B, 9A); writing
   them down costs nothing and stops each lane asking.
2. **`--_menu-*` is one shared family.** Every menu surface reads it, so one
   Desk recipe draws them all. A rename would touch eight components for no
   visible gain. No other shared family without a line in the contract.
3. **`--_fab-inset` renamed to `--_floating-action-button-inset`.** The
   prefix is the full `data-ds` value, without short aliases.
4. **Layout and component attributes (anatomy rule 11).** The attributes in
   use are listed in a table. `data-variant` never stands in for a shared
   axis.
5. **Rule 12 covers controls only.** A control's `md` is 32px. Every other
   component's `md` is the middle of its own scale, from tokens.
6. **Container takes `width`, not `size`** (`sm`, `md`, `lg`, `xl`, `full`,
   default `lg`, attribute `data-width`). `size` is the control axis, and a
   page width is not a control size. Overrides the prop name in order 1.8.
7. **The contract suite keeps Studio as its single run style** while
   Neutral is `proposed`. Neutral joins the single runs once the owner
   approves it.
8. **Tokens added to the contract** (`added`): `delay.feedback` 2s (how
   long CopyButton shows copied or failed; was `delay.peek-hide`, 600ms),
   `duration.pulse` 1.4s (StatusDot), `z.raised` 1, `scale.menu-enter`
   0.97, `size.icon.xl` 36px, `size.container.sm` to `xl` (30, 48, 68.75,
   84rem), `size.grid.item-min.sm` to `lg` (10, 15, 24rem), `size.measure`
   33.75rem. Component token `menu.width.max` 400px. Each equals the value
   its component computed before, except the feedback delay, which grows to
   the 2s that was asked for.
9. **Scrollbar thumb meets 3:1** on body and surface 1 to 5 in every style
   and scheme (SC 1.4.11), with the hover one step stronger. Light schemes
   and Neutral dark alias `color.text.subtle` (hover `muted`); Studio and
   Desk dark use an opaque `#b8b8b8` (hover `text.default`), since muted
   text is only 2.5:1 on their surface 5. The contrast gate measures the
   pair now.
10. **Motion ids.** `press` names the press of Button, IconButton,
    WindowControls, Pagination and ToggleGroup. `fade` names the focus glow
    and mark fades of Input, Textarea, the field family, Checkbox,
    CheckboxGroup, RadioGroup, RadioCard, Rating, Slider, RangeSlider,
    Switch, NumberField and ScrubInput. There is no `toggle` pattern: the
    Switch thumb slide stays component CSS. The manifest schema's `motion`
    is an enum of `none` plus the catalog ids, generated by `npm run gen`.
    `none` is written for a component with no motion; only layout
    components leave the key out. On the web Button does not play `press`
    yet; the id names the pattern the component owes.
11. **`npm run gen` writes everything generated:** barrels and routes
    (`scripts/gen-index.ts`), the token build, the registry
    (`packages/registry/build.ts`, which reads the token CSS) and the docs
    pages and llms files (`npm run gen -w @the-system/docs`). `npm run
    check` runs the same `npm run gen`, so `registry.json` stays fresh the
    way `manifests.gen.json` does.
12. **Root engines: Node `>=22.23.4`**, what astro 7.4.11 needs.
13. **The CLI declares its workspace packages** (`@the-system/icons`,
    `lint`, `registry`) as dependencies. `tsx` and `typescript` stay
    undeclared while packages export source: as runtime dependencies of a
    published CLI they are a question for the owner at the release wave.
14. **The doctor knows copied components.** Its `packages` entries take
    path patterns, and the default adds `**/ds/react/components/*`, so an
    app on registry files is checked like one on `@the-system/react`.
15. **Docs (order 1.15):** English at the root and Arabic under `/ar/`;
    generated pages and twins are not committed; the preview points at
    `DOCS_GALLERY_URL`; plain Markdown, not MDX; smart punctuation off; the
    search shortcut chip is hidden (WCAG 2.5.3). `llms.txt` is served at
    the docs root, where `ds init` points.
16. **Round 2 rules in the anatomy contract** (rules 5, 6, 7 and 13 to
    18): roving group options use native `disabled`; `start` is drawn in
    an `icon` part where one exists (Badge, Chip); a landmark's `label`
    names the `nav` and is never drawn (Sidebar, Rail, Navbar); live roles
    are opt in; built in words follow `lang ?? theme.lang`; a control that
    removes itself moves focus first; marks use `state.*.border` or
    `primary.border`; indeterminate under reduced motion is a still shape;
    `data-visually-hidden` is a base rule. Added base name `padding-end`.
17. **Combobox and Autocomplete run as fields in the contract suite**, with
    no `contract.trigger`, because their popup never takes focus (lane 3C,
    decision 2). Their `contract.keys` hints cover the popup.
18. **The list family popup** sits on `z.menu`, its rows follow
    `list.row.height`, and its extra private names (`-highlight`,
    `meta-fg`, `mark-weight`, `max-height`, `separator-color`) are part of
    the shared `--_menu-*` family.
19. **Field anatomy** (order 1.2.1): root, `label` (a Label root carrying
    `data-part="label"`), `description`, `error` (a FieldError root carrying
    `data-part="error"`). The required mark is Label's part.
20. **CheckboxGroup keeps its own `error` part.** A FieldError needs a Field
    context; the group's error part follows the same look and wiring.
21. **AspectRatio is one div** with the native `aspect-ratio` property, not
    Radix AspectRatio, so `className`, `style` and `ref` reach the ratio box
    and React and Angular render the same DOM. Overrides order 1.8.
22. **Navigation sizes and states.** The Rail's 44px target comes from the
    platform axis, not from `md`. Dock `md` tiles are 44px. Tabs triggers use
    native `disabled`.
23. **Inert controls pass navigation keys.** A disabled or loading Button,
    and a disabled Link, still hand arrows, Home, End, Page keys and Tab to
    `onKeyDown`, so roving groups (Toolbar, ToggleGroup, Tabs) move past
    them. Every other key, activation and Delete included, is swallowed.
    Toolbar may now pass the system `disabled` and drop its `inertProps`
    helper (left to the Toolbar owner).
24. **Contract hints for components that open another one:**
    `contract.opens` names the opened root (`dropdown-menu` for SplitButton,
    Menubar, Breadcrumbs and LanguageSwitch), and a key hint may `open` a
    trigger first and expect `focus-returns`. Gallery and docs slugs use the
    same kebab case as `data-ds` (`otp-field`).

## Structure (2026-11-12)

1. **Placeholders in one file.** `ds.config.json` holds the name, the package
   scope, the CSS prefix and the CLI name. The token build and the generators
   read it. Package names still repeat the scope, so a rename is this file
   plus a find and replace of `@the-system/`. A rename script comes with the
   release wave.
2. **Packages export source.** During development every package exports its
   TypeScript and CSS source (`exports` points at `src`). Vite, Vitest, Next
   (`transpilePackages`) and the Angular builder compile it. Compiled `dist`
   builds come with the release wave. Reason: no build step between a
   subagent's edit and the gallery.
3. **Playwright pinned to 1.63.0** to match the Chromium that is installed in
   the container.
4. **Dev tools outside the "use freely" list:** `typescript-eslint` (needed to
   lint TypeScript), `ajv` (manifest schema validation), `@types/*`,
   `@testing-library/user-event`, `@testing-library/jest-dom`. All dev only,
   none ships.
5. **Workspace `check` scripts.** `npm run check` runs the root steps, then
   `npm run check` in every workspace that defines one. Angular and React
   Native packages hook their own test runners in that way.
6. **Manifest additions.** The schema adds three optional keys the prompt did
   not list: `parts` (named sub components), `contract` (hints for the
   generated contract suite) and, for templates, `regions`, `uses`, `data`.

## Theme and styles (2026-11-12)

1. **`Theme` takes inline styles through `css`.** Its `style` prop is the
   style axis. Recorded in `docs/contracts/frameworks.md`.
2. **`style.json` gains `status` and `proposedSchemes`.** They mark looks that

3. **`defaultDensity` is `default` for Studio and Desk.** The base token

   the dials table describe how the look reads, not the axis value.
4. **Arabic: only small text moves one step up.** Body text keeps its step.
5. **Import order for consumers.** Only CSS outside layers is certain to win.
   A consumer that uses its own layers imports the system first.

## Components (2026-11-12)

1. **Toasts above a modal dialog.** While a modal dialog is open, toasts stay
   visible, are read by screen readers and can be clicked, but keyboard focus
   stays in the dialog, so F8 and Tab do not reach them. A trick that broke
   the focus trap was removed after review because it silenced other focus
   handlers on the page. To compensate, error toasts and toasts with an
   action never time out, so they are still there when the dialog closes.
2. **The toast store owns time, not Radix.** Durations: 4s, warning 6s,
   danger and action toasts stay until closed. `toast.configure` lets an app
   lengthen them (WCAG 2.2.1).
3. **Window lights keep their order in RTL** (close, minimize, zoom from the
   left) and show idle dots at rest, as the source does.
4. **Dialog has a `panel` part.** The root is a fixed layer that holds the
   backdrop and the panel, so the backdrop belongs to the dialog.
