# The system

One design system, one component contract. Each look is a style pack that
plugs in. It ships for React, Angular and React Native.

- Styles: studio, desk, neutral, liquid, paper
- Schemes: dark and light for every style
- Densities: compact, default, comfortable
- Direction and language: LTR and RTL, English and Arabic

Status: in development. See `STATE.md`.

## Use

```bash
npm install
```

```bash
npm run check
```
