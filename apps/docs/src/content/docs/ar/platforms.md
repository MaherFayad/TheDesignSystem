يعمل النظام على الويب عبر React وAngular، وعلى iOS وAndroid عبر React Native.
للمكون الاسم نفسه والخصائص نفسها والقيم نفسها على كل المنصات، ويحدد محور
`platform` وإطار العمل ما يتغير.

## محور المنصة

| القيمة | مجال التطبيق |
| --- | --- |
| `web` | متصفحات الحواسيب المكتبية والمحمولة، وكل جهاز لا تكتشفه القيمة `auto`، وهي ما يعرضه الخادم |
| `ios` | iPhone وiPad، في المتصفح وفي React Native |
| `android` | هواتف Android وأجهزته اللوحية، في المتصفح وفي React Native |
| `macos` | أعراف سطح المكتب في macOS، ولا تختار إلا بقيمة صريحة |
| `auto` | قيمة مدخلة فقط، وتعطي `ios` على iPhone وiPad، و`android` على أجهزة Android، و`web` في غيرها |

عنصر Theme الخارجي دون الخاصية `platform` قيمته `auto`. يعرض الخادم القيمة
`web`، ثم تكتب القيمة المكتشفة مرة واحدة بعد التحميل. لإيقاف الاكتشاف في تطبيق
تمرر القيمة `platform="web"`. يكتب Theme السمة `data-platform` على عنصره، ولا
يقرؤها المكون إلا حيث تختلف المنصات فعلا. في React Native تتبع القيمة `auto`
الجهاز، وتحمل كائنات السمات مقاسات كل منصة.

### في هذا الموقع

يبدأ مبدل المنصة في الشريط العلوي على الخيار التلقائي، ويعرض المنصة المكتشفة
لجهازك، مثل "تلقائي: iOS" على iPhone. عند اختيار منصة تظهر بها كل الصفحات وكل
المعاينات، ويحفظ الاختيار في كل الصفحات إلى حين العودة إلى الخيار التلقائي.
والعنوان الذي يحمل `?platform=android` يعرض تلك المنصة في تلك الصفحة فقط، مقدمة
على الاختيار المحفوظ.

## حسب إطار العمل

| إطار العمل | الحزمة | المظهر | السلوك |
| --- | --- | --- | --- |
| React | `@the-system/react` | `@the-system/css`، مشترك مع Angular | Radix وReact Aria |
| Angular | `@the-system/angular` | ملفات CSS نفسها دون أي تغيير | Angular CDK وAngular Aria |
| React Native | `@the-system/native` | كائنات سمات مولدة ودالة أنماط لكل مكون | RN Primitives |

تعرض [صفحة التغطية](/ar/frameworks/coverage/) الجاهز في كل إطار عمل.

## الأهداف والخطوط حسب المنصة

- الأهداف: 24px على الويب (WCAG 2.2، المعيار 2.5.8)، و44px في قوالب اللمس،
  و44pt على iOS، و48dp على Android.
- يتكبر النص في التطبيقات حتى 200% مع إعداد النظام، لذا لا يثبت ارتفاع أي
  حاوية نص.
- من اليمين إلى اليسار: يتبع الويب السمة `dir` على Theme، ويتبع React Native
  الإعداد `I18nManager` ويتطلب إعادة تشغيل التطبيق بعد التغيير.
