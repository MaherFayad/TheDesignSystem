النظام هو نظام تصميم يقوم على عقد واحد للمكونات، وعدة أنماط بصرية، وثلاثة
أطر عمل. لكل مكون ملف تعريف واحد، وملف CSS واحد يشترك فيه React وAngular،
ودالة أنماط في React Native. يغير النمط البصري الرموز التصميمية والوصفات
والأيقونات والحركة، ولا يغير البنية ولا السلوك.

## التجربة في المتصفح

- [فتح معرض المكونات](gallery:/?dir=rtl&lang=ar): أمثلة React كلها، مع شريط
  لتغيير النمط والسمة والكثافة والاتجاه واللغة.
- [فتح صفحة التفاعلات](gallery:/interactions?dir=rtl&lang=ar): بطاقة لكل
  تفاعل، مثل الضغط والتركيز والفتح والإغلاق.
- [فتح الأمثلة كلها في صفحة واحدة](gallery:/all?dir=rtl&lang=ar).

### عناصر الاختبار

- الأنماط: التبديل بين Neutral وStudio وDesk. تبقى البنية والسلوك كما هي،
  وتتغير الرموز التصميمية والوصفات والأيقونات والحركة. مثال:
  [الزر بنمط Desk والسمة الداكنة](gallery:/c/button?style=desk&scheme=dark&dir=rtl&lang=ar).
- السمة: الفاتحة والداكنة في كل نمط.
- الكثافة: المضغوطة والافتراضية والمريحة.
- العربية من اليمين إلى اليسار: الاتجاه `rtl` واللغة `ar`. ينعكس التخطيط،
  وتنقلب الأيقونات الاتجاهية، ويظهر النص العربي للأمثلة.
- في صفحة المكون، فوق المعاينة الإعدادات نفسها، وتحتها رابط لفتحها صفحة
  كاملة في المعرض.

## محتويات النظام

| الحزمة | المحتوى |
| --- | --- |
| `@the-system/tokens` | الرموز التصميمية بصيغة DTCG ومخرجاتها لـ CSS وللتطبيقات الأصلية ولـ Figma |
| `@the-system/css` | ملف الضبط والأساس وملف CSS لكل مكون |
| `@the-system/styles` | الأنماط البصرية: قيم الرموز والوصفات والأيقونات والحركة |
| `@the-system/react` | مكونات React 19 |
| `@the-system/angular` | مكونات Angular على ملفات CSS نفسها |
| `@the-system/native` | مكونات React Native على كائنات سمات مولدة |
| `@the-system/shared` | منطق TypeScript خالص تشترك فيه أطر العمل كلها |

## قراءة صفحة المكون

تنشأ كل صفحة مكون من ملف تعريفه في `packages/manifest/src/component/` ومن
ملفات العرض، وأقسامها بترتيب ثابت: العنوان وملخص في سطر واحد، والحالة في React
وAngular وReact Native، ومعاينة حية مع إعدادات النمط والمظهر والمنصة والكثافة
والاتجاه واللغة، ثم قسم لكل حالة عرض (الخيارات، وعنصر واحد، وعدة عناصر، والنص
الطويل، والنص العربي، والتحميل، وعدم الإتاحة وغيرها)، ولكل قسم معاينة حية
والشيفرة الفعلية لكل إطار عمل. بعد الأمثلة: حالات الاستخدام، وحالات تجنب
الاستخدام، والبدائل، والبنية، والخصائص، والحالات، وإمكانية الوصول مع معايير
WCAG 2.2، وقواعد المحتوى بالإنجليزية والعربية، والرموز التصميمية، والحركة،
والأخطاء الشائعة. يظهر إطار العمل غير الجاهز بحالة "ضمن الخطة".

يظهر وصف المكونات في الصفحات العربية بالإنجليزية إلى حين إضافة نص عربي إلى
ملفات التعريف.

## للوكلاء البرمجيين

- يسرد الملف [`/llms.txt`](/llms.txt) كل دليل وكل مكون مع رابط نسخة Markdown.
- يجمع الملف [`/llms-full.txt`](/llms-full.txt) الصفحات الإنجليزية كلها في ملف واحد.
- لكل صفحة نسخة Markdown على المسار نفسه بإضافة `.md`، مثل
  [`/ar/components/button.md`](/ar/components/button.md).
