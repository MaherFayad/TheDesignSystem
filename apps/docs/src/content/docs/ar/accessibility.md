title: إمكانية الوصول
description: قواعد WCAG 2.2 بمستوى AA التي يلتزم بها كل مكون.
---

يستوفي كل مكون معايير WCAG 2.2 بمستوى AA في كل نمط ومظهر واتجاه. وتنطبق
المعايير نفسها على شاشات React Native، إذ ترتبط الأدوار والحالات بـ VoiceOver
وTalkBack عبر ملف التعريف.

| WCAG 2.2 | القاعدة |
| --- | --- |
| 1.4.3 | تباين النص 4.5:1 على كل سطح يمكن أن يظهر عليه، بما في ذلك الزجاج فوق أسوأ خلفية |
| 1.4.11 | تباين حدود عناصر التحكم وحلقات التركيز وعلامات الرسوم البيانية 3:1 |
| 1.4.4 و1.4.10 | عدم منع تكبير الصفحة، ولا تمرير أفقي عند 320px، ونص التطبيقات الأصلية يتكبر حتى 200% |
| 1.4.13 | التلميحات من مكون Tooltip فقط، دون السمة الأصلية `title` |
| 2.1.1 | خريطة مكتوبة للوحة المفاتيح لكل مكون |
| 2.2.2 و2.3.1 | زر إيقاف لكل ما يعمل أكثر من خمس ثوان، ولا وميض أكثر من ثلاث مرات في الثانية |
| 2.4.7 و2.4.11 | حلقة تركيز بسماكة 2px، وهامش تمرير تحجزه الأشرطة الثابتة والعائمة |
| 2.5.7 | لكل سحب أو تمرير بديل بزر أو بمفتاح |
| 2.5.8 | حد أدنى للأهداف 24px على الويب، و44px في قوالب اللمس، و44pt في iOS، و48dp في Android |
| 3.3.7 و3.3.8 | عدم طلب المعلومة مرتين، وحقول رمز التحقق تقبل اللصق ومديري كلمات المرور |
| 4.1.3 | الإشعارات العابرة وأدوار المحادثة تعلن مرة واحدة |

## في صفحة كل مكون

يعرض قسم "إمكانية الوصول" الدور، وسلوك التركيز، وما يعلنه قارئ الشاشة، وخريطة
لوحة المفاتيح كاملة من ملف التعريف. وفي الصفحات من اليمين إلى اليسار تتبع مفاتيح
الأسهم اتجاه القراءة.

## طريقة التحقق

- يشغل `npm run contract` حزمة اختبارات العقد المولدة من ملفات التعريف: البنية
  وخريطة لوحة المفاتيح وفحص axe لكل مكون.
- يشغل `npm run a11y` فحص axe على كل صفحة في المعرض بالإنجليزية والعربية.
- أزواج التباين بوابة إلزامية لكل نمط ومظهر.
