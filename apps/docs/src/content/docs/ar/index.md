النظام هو نظام تصميم يقوم على عقد واحد للمكونات، وعدة أنماط بصرية، وثلاثة
أطر عمل. لكل مكون ملف تعريف واحد، وملف CSS واحد يشترك فيه React وAngular،
ودالة أنماط في React Native. يغير النمط البصري الرموز التصميمية والوصفات
والأيقونات والحركة، ولا يغير البنية ولا السلوك.

## محتويات النظام

| الحزمة | المحتوى |
| --- | --- |
| `@the-system/tokens` | الرموز التصميمية بصيغة DTCG ومخرجاتها لـ CSS وللتطبيقات الأصلية ولـ Figma |
| `@the-system/css` | ملف الضبط والأساس وملف CSS لكل مكون |
| `@the-system/styles` | الأنماط البصرية: قيم الرموز والوصفات والأيقونات والحركة |
| `@the-system/react` | مكونات React 19 |
| `@the-system/angular` | مكونات Angular على ملفات CSS نفسها |
| `@the-system/native` | مكونات React Native على كائنات سمات مولدة |
| `@the-system/shared` | منطق TypeScript خالص تشترك فيه أطر العمل كلها |

## قراءة صفحة المكون

تنشأ كل صفحة مكون من ملف تعريفه في `packages/manifest/src/component/`،
وأقسامها بترتيب ثابت: الملخص، والمعاينة الحية، وحالات الاستخدام، وحالات عدم
الاستخدام، والبدائل، والبنية والخيارات، وقواعد المحتوى، وإمكانية الوصول،
والأخطاء الشائعة، والأنماط، ثم تبويب للشيفرة لكل إطار عمل. يظهر إطار العمل
غير الجاهز بحالة "ضمن الخطة".

يظهر وصف المكونات في الصفحات العربية بالإنجليزية إلى حين إضافة نص عربي إلى
ملفات التعريف.

## للوكلاء البرمجيين

- يسرد الملف [`/llms.txt`](/llms.txt) كل دليل وكل مكون مع رابط نسخة Markdown.
- يجمع الملف [`/llms-full.txt`](/llms-full.txt) الصفحات الإنجليزية كلها في ملف واحد.
- لكل صفحة نسخة Markdown على المسار نفسه بإضافة `.md`، مثل
  [`/ar/components/button.md`](/ar/components/button.md).
