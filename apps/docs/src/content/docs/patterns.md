---
title: Patterns
description: Screens and flows made of components. Planned for wave 3.
---

A pattern solves one task with several components: a sign in with a one time
code, a filter bar over a table, a consent screen. Each pattern will have a
manifest of kind `pattern`, a demo in every style and a page here, generated
the same way as a component page.

Status: planned. The 60 patterns are listed in the plan for wave 3: forms,
data, AI, navigation, feedback and status, onboarding and help, privacy and
trust.

Until then, every component page shows the cases a pattern needs: empty, one
item, many items, long text, Arabic, loading, error and disabled.
